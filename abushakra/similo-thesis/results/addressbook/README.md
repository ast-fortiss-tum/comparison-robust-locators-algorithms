# AddressBook benchmark (real multi-release chain, 2026-11-19/20)

* `dump/*.csv`: per-pair outcomes (algorithm, site, date, element, locator_class, element_class, outcome right/wrong/abstain, top_score, found_in_top10). 1,958 pairs, 18 algorithms. The XPath-based algorithms were run with `STRIP_XMLNS=1` (see below); Similo family, COLOR and VISTA do not use XPath and are unaffected.
* `summary_riskcoverage.txt`: right / wrong / silent, coverage and precision, and each scored algorithm limited to the same number of answers as each fixed algorithm (`../../scripts/analysis/riskcoverage.py`). `summary_riskcoverage_BEFORE_xmlns_fix_INVALID_for_xpath_algorithms.txt` is the first run: invalid for the XPath-based algorithms, kept only as a record.
* `ground_truth_final_slim.csv`: the 14,028 aligned element pairs (74 consecutive release pairs; 67 with a changed locator; 268 human-validated). `ground_truth_dropped.json`: the 88 pairs dropped after review. `selected_pairs_plan.json`: the 1,970 pairs given to the algorithms (all changed or human-validated pairs plus a random stable sample, stratified by release pair); `manifest_plan_chunk_*.csv`: import status (12 rejected: target not visible).
* `human_verdicts_round1/` (115 pairs) and `human_verdicts_round2/` (185 pairs): one JSON document per reviewed pair (verdict same/diff). Round 1 ids refer to the first alignment, round 2 ids to `align_all.py` v1; the `*_idx.json` files give id to verdict. 24 pairs were judged different and removed.
* `app_faults.md`: releases whose own suite fails, with causes. `replay_run_status.json`, `capture_run.log`, `pipeline.log`, `algos.progress`: run records.

Results (accuracy / coverage / precision, 1,958 pairs): OptimizedSimilo 99.1 / 100 / 99.1; LegacySimilo 98.7; COLOR 98.6; MultiLocator+VISTA 98.7 (100% coverage, 25 wrong); MultiLocator 98.4 (99.3 / 99.1; paper repair identical); SIDEREAL 96.7; RobulaPlus 96.3; absXPath 95.3; SeleniumIDE 92.3; Montoto 91.6; VISTA 81.1 (96.6 / 83.9). The benchmark is nearly saturated.

Method notes. Alignment: per test, difflib on (command, value, tag of the resolved element); Languages aligned by flag image. Ground truth = the developers' suites pass on each release, so a kept step selects the same logical element in both releases. Captures: viewport screenshots, so element boxes stay in viewport coordinates (scroll written as 0). 3.3.0 is replayed with the Languages test skipped.

**Namespace artefact.** 1,171 of the 1,958 old pages declare `xmlns="http://www.w3.org/1999/xhtml"` on `<html>`. The namespace-aware JDOM tree then matches no unprefixed XPath, so every XPath-based algorithm failed to build a locator (MultiLocator answered 0 of 1,171 such pages and 748 of 787 others). `STRIP_XMLNS=1` (patch in `../multilocator_perf/patches/Load_scala_strip_xmlns_switch.diff`, off by default) removes the default namespace, which is how a browser treats these pages. No page of Wayback, Excalidraw, Slickgrid, BEWT or ReproBreak declares it, so earlier results there are unaffected.
